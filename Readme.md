# Collision 2D in C using raylib

So, I have used [raylib](https://github.com/raysan5/raylib) to make this.

## Requirements

- [raylib](https://github.com/raysan5/raylib)
- gcc / clang
- Any IDE or text editor

## Run

Clone the repo

```bash
git clone https://github.com/AniDevWired/Raylib-Collision2D.git
cd Raylib-Collision2D
```

make my project

```bash
make main
make run
```

It's pretty simple and begginer friendly project.
